# dsa-problems

Repositório da disciplina de Estrutura de Dados 2 (Quinto Período).

Cada atividade entregue vive em uma branch própria, é revisada por um Pull Request
e é integrada à `main`, que conserva o histórico completo do semestre.

## Atividades

| Branch | Atividade | Pasta |
|---|---|---|
| `atividade-bst` | Operações de Árvores Binárias de Busca (BST) em Go | `00-` a `05-` |

## Como executar

Cada pasta é um módulo Go independente:

```
cd 01-criar-e-inserir-bst
go run main.go
```
